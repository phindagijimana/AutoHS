Contact
=======

Questions, bug reports, and collaboration inquiries are welcome.

Issues and feature requests
---------------------------

Use the GitHub issue tracker — this is the fastest route for anything reproducible:

`github.com/phindagijimana/AutoHS/issues <https://github.com/phindagijimana/AutoHS/issues>`_

When reporting a problem, include the AutoHS version (``python run.py --version``), the full
command line, and the last ~50 lines of logs. See :doc:`troubleshooting` first for common fixes.
